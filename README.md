# Дневник эмоций

Веб‑приложение (PWA) по PRD: за несколько секунд зафиксировать эмоцию — отметить на палитре, выбрать из полосы эмоций или наговорить голосом. AI‑ассистент (Claude) сам определит эмоцию, триггер, мысль и задетую потребность.

**Принцип: «Поделилась и забыла».**

## Разделы

- **Сегодня** — «Как ты сейчас?»: цветная палитра состояний (энергия × приятность), прокручиваемая полоса эмоций и меток, кнопки «Рассказать» (наговорить) и «Сохранить без деталей».
- **Рассказать** — запись голосом или текстом → ассистент уточняет «Похоже, ты чувствуешь… Это так?» и «Что сильнее всего?» (+ один вопрос при необходимости) → «Состояние зафиксировано» с точкой на палитре и метками.
- **История** — лента дней с цветными отметками, карточки записей, удаление.
- **Инсайты** — паттерны (карта состояний, что расстраивает, корни, что радует, время суток, AI‑портрет) и практики для повторяющихся реакций.

## Как запустить

Статический сайт без сборки — опубликован на GitHub Pages.

Чтобы работал разбор рассказов, откройте ☰ Настройки и вставьте личный ключ API с [console.anthropic.com](https://console.anthropic.com/settings/keys). Отметки на палитре работают и без ключа.

## Приватность

- Все записи хранятся только в браузере пользователя (`localStorage`) — у каждого человека и устройства свой дневник.
- Ключ API хранится только на устройстве и отправляется напрямую в Anthropic.
- При признаках кризиса показывается карточка с контактами линий помощи.
- Приложение не заменяет психолога и не ставит диагнозов.
