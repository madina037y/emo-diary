# Дневник эмоций

Веб‑приложение (PWA) по PRD: за несколько секунд зафиксировать эмоцию голосом или текстом, а AI‑ассистент (Claude) сам определит эмоцию, триггер, мысль и задетую потребность.

**Принцип: «Поделилась и забыла».**

## Разделы

- **Состояние** — главный экран: кнопка «Что сейчас случилось?», эмоции дня, график недели, наблюдение, последняя запись.
- **История** — дневник по дням, фильтр по семействам эмоций, карточка записи, удаление.
- **Рассказать** — диалог с ассистентом: рассказ → (один уточняющий вопрос) → поддержка и карточка разбора.
- **Паттерны** — эмоциональный профиль и AI‑портрет (после 3 записей).
- **Работа** — повторяющиеся реакции, разбор цикла, практика из 3 шагов, счётчик «Попробовала сегодня», диалог.

## Как запустить

Это статический сайт без сборки: откройте `index.html` или опубликуйте папку на GitHub Pages.

Чтобы работал разбор, откройте ⚙︎ Настройки и вставьте личный ключ API с [console.anthropic.com](https://console.anthropic.com/settings/keys). Без ключа записи всё равно сохраняются, а разобрать их можно позже.

## Приватность

- Все записи хранятся только в браузере пользователя (`localStorage`) — у каждого человека и устройства свой дневник.
- Ключ API хранится только на устройстве и отправляется напрямую в Anthropic.
- При признаках кризиса показывается карточка с контактами линий помощи.
- Приложение не заменяет психолога и не ставит диагнозов.

## Голос

Кнопка микрофона использует распознавание речи браузера (Chrome, Safari на iOS 14.5+). Если оно недоступно — используйте диктовку клавиатуры телефона.
